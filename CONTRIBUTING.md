# Contributing to sdr-visualizer

Thanks for your interest. This project has a deliberately tight scope. Read
[AGENTS.md](AGENTS.md), the canonical guide for contributors and coding agents,
before making changes. It covers setup, development, required validation,
architecture, sibling parity, and contribution discipline.

Discuss non-trivial features in an issue before implementation. Use the
[PR template](.github/PULL_REQUEST_TEMPLATE.md) to describe your change and record
validation. By participating, you agree to follow the
[code of conduct](CODE_OF_CONDUCT.md). Report security issues privately as described
in [SECURITY.md](SECURITY.md).

For maintainer release work, use the full candidate, publication, and announcement
checklist in [docs/RELEASING.md](docs/RELEASING.md).
